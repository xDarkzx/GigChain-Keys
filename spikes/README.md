# Spikes (throwaway)

Experiments that answer a question. Nothing here ships; product code is
written fresh from what a spike proves.

- `engine_spike/` — can OpenStage play a VST3 instrument from a MIDI keyboard
  through ASIO with gig-worthy latency? Build with
  `powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Preset spike -NoTest`.
