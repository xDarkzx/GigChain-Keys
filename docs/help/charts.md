# Chord charts

Every song can show its **chords and lyrics**, with each chord sitting over
the word it changes on. You edit the chart right where you read it, in the
**Chart** tab of the Edit view. On stage the same chart fills the screen
([Perform mode](perform.md)), and [Practice mode](practice.md) turns its
chords into notes to learn.

## Get the chords in

Any of these works:

- **Paste:** copy a song's chords and lyrics from a chord website or a
  document, then click **Paste chords** (or press **Ctrl+V** in the Chart
  tab). The site's extras (ads, tabs, menus) are cleaned out and the chords
  placed over their words. Not happy? Click **Undo**.
- **Import file…** reads a chord sheet: *.txt*, *.cho*, *.chopro*,
  *.chordpro*, *.crd*, *.pro*, *.onsong*.
- **Type:** click **Type the words…** and type the lyrics. Then add the
  chords as below.

## Add and move chords

- **Click above a word** to put a chord on it. Type the chord (*G*, *Am7*,
  *D/F#*, *C#m7*) and press **Enter**.
- **Drag a chord** left or right: it snaps onto the word you drop it on.
- **Chord…** in the toolbar opens the chord palette: type a chord, then drag it
  onto any word.
- **Double-click a chord** to change it. **Right-click** it, or drag it onto
  **Remove**, to take it off.

## Lyrics

Click a lyric line and type, just like a text editor. **Enter** starts a new
line; **+ Click to type a new line** adds one at the end.

## Sections

Songs are split into sections: *Intro, Verse, Pre-Chorus, Chorus, Bridge,
Solo, Outro*.

- **+ Section** adds one at the end (pick a name from the list).
- **Double-click a section's title** to rename it (*Verse 2*, *Big chorus*).
- **Click a title** to go to that section.

Under each title you see which instruments play in it and how many bars it
lasts. See [Sections, tempo and backing tracks](sections-and-tempo.md).

## Edit as text (ChordPro)

**⋯ > Edit as text (ChordPro)** shows the chart as plain text, for those who
like to type it all. Chords go in [brackets] right before the word they
change on, and a line like *{comment: Chorus}* starts a section:

```
{comment: Verse}
[G]Amazing [G7]grace, how [C]sweet the [G]sound
```

Click **Done** to go back.
