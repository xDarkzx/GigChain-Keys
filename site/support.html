Questions

Is GigChain Keys free?

Yes, completely: no ads, no account, no licence key and no paid version. Donations and sponsors keep it that way.

Do supporters get extra features?

No. Everyone gets the same app, with every feature. Support pays for the work, not for access.

What's the difference between donating and sponsoring?

Donating is a one-time gift through Buy Me a Coffee, with no account needed. Sponsoring is ongoing support through GitHub Sponsors, and needs a GitHub account. Both go to the same place: GigChain Keys.

Not using it yet? It's free on Windows, Mac and Linux.
